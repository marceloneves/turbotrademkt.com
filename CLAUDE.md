# turbotrademkt.com

Site em Astro. Build: `npm run build` (saída em `dist/`).

## Log de trabalho

Ao terminar uma sessão com mudanças no projeto (ou antes de cada commit), acrescente uma entrada em `log/AAAA-MM-DD.md`, usando a data do dia. Anexe ao fim do arquivo; nunca sobrescreva entradas anteriores. Escreva em português.

Formato da entrada:

```markdown
## HH:MM — título curto

- **O que foi feito:** ...
- **Arquivos principais:** ...
- **Por quê:** ...
- **Commit:** `hash` (ou "sem commit")
- **Pendências:** ... (ou "nenhuma")
```

A pasta `log/` é versionada no git.
